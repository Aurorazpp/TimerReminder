# 定时提醒 Android APP — 设计方案

## 📋 需求总览

| 项目 | 内容 |
|:---|:---|
| **开发方式** | 原生 Kotlin + Jetpack Compose |
| **UI风格** | Material 3 现代简洁风 |
| **目标平台** | Android |
| **最低版本** | Android 8.0 (API 26) — 适配 AlarmManager 精确闹钟 |

## 🎯 核心功能

### 1. 提醒类型
- **一次性提醒**：指定具体日期时间，到点触发
- **每日提醒**：每天固定时间触发
- **每周提醒**：选择星期几，固定时间触发
- **每月提醒**：选择每月第几天触发
- **自定义间隔**：每隔 N 小时 / N 分钟触发
- **工作日提醒**：周一至周五触发

### 2. 提醒方式（可自由组合开关）
| 方式 | 说明 |
|:---|:---|
| 🔔 **通知** | 状态栏通知，带提醒标题和内容 |
| 🔈 **响铃** | 播放铃声，可选择内置铃声 |
| 📳 **震动** | 伴随响铃或通知震动 |

### 3. 附加功能
- 🏷️ **标签/分类**：自定义标签（工作、吃药、喝水等）
- 🔄 **贪睡**：提醒时可选"稍后提醒"，延迟 X 分钟
- 📱 **桌面小部件**：主屏显示最近待触发的提醒
- 🎵 **多铃声选择**：内置多首铃声，每条提醒可独立选择

## 🏗️ 技术架构

### 整体架构：MVVM + Repository 模式

```
┌─────────────────────────────────────────────────┐
│                  UI 层 (Compose)                  │
│  ┌──────────┐  ┌──────────┐  ┌────────────────┐ │
│  │ 提醒列表页 │  │ 添加/编辑 │  │ 闹钟响铃弹窗页  │ │
│  └─────┬────┘  └─────┬────┘  └───────┬────────┘ │
├────────┼──────────────┼──────────────┼────────────┤
│        └──────┬───────┘              │            │
│           ViewModel                   │            │
├───────────────┼───────────────────────┼────────────┤
│               ▼                       ▼            │
│           Repository (数据仓库)                   │
├───────────────┼───────────────────────┼────────────┤
│       ┌───────┴───────┐       ┌──────┴───────┐   │
│       │  Room Database │       │ AlarmManager │   │
│       │  (SQLite本地)  │       │ + WorkManager│   │
│       └───────────────┘       └──────────────┘   │
└─────────────────────────────────────────────────┘
```

### 关键组件

| 组件 | 作用 |
|:---|:---|
| **Room** | 本地 SQLite 数据库，存储提醒信息、标签等 |
| **AlarmManager** | 精确定时触发，设置一次性/周期性闹钟 |
| **BroadcastReceiver** | 接收系统闹钟广播，触发提醒逻辑 |
| **Foreground Service** | 响铃时在前台运行，保证不被系统杀死 |
| **NotificationManager** | 创建通知渠道、发送通知 |
| **MediaPlayer** | 播放铃声 |
| **Vibrator** | 控制震动 |
| **WorkManager** | 辅助处理定时刷新小部件等后台任务 |

### 数据模型 (Room Entity)

```
Reminder
├── id: Long (主键)
├── title: String (标题)
├── description: String? (描述/备注)
├── type: Enum (ONCE / DAILY / WEEKLY / MONTHLY / INTERVAL / WEEKDAY)
├── triggerTime: Long? (一次性提醒的具体时间戳)
├── intervalMinutes: Long? (自定义间隔的分钟数)
├── dayOfWeek: Int? (每周：位标记，bit0=周一 ~ bit6=周日)
├── dayOfMonth: Int? (每月：1-31)
├── hour: Int (时)
├── minute: Int (分)
├── ringtoneUri: String? (铃声URI)
├── isNotificationEnabled: Boolean (是否通知)
├── isRingEnabled: Boolean (是否响铃)
├── isVibrationEnabled: Boolean (是否震动)
├── tagId: Long? (标签ID，外键)
├── isEnabled: Boolean (是否启用)
├── isSnoozed: Boolean (是否在贪睡中)
├── snoozeEndTime: Long? (贪睡结束时间)
├── createdAt: Long
└── updatedAt: Long

Tag
├── id: Long (主键)
├── name: String (标签名)
├── color: Int (颜色值)
└── icon: String? (图标)
```

## 📱 页面规划 (Compose UI)

### 1. 主页面 — 提醒列表
- 顶部：APP标题 + 添加按钮
- 列表：所有提醒，按时间排序
  - 每条显示：标题、时间、重复规则、标签色块、开关
  - 点击进入编辑
  - 左滑删除
- 空状态：友好的空列表提示
- 浮动按钮：快速添加

### 2. 添加/编辑页面
- 标题输入
- 提醒时间选择器（时/分）
- 重复类型选择（一次性 / 每日 / 每周 / 每月 / 间隔）
- 根据类型显示对应配置项（星期选择、日期选择、间隔输入）
- 提醒方式开关（通知 / 响铃 / 震动）
- 铃声选择
- 标签选择/创建
- 保存按钮

### 3. 闹钟响铃页面 (全屏弹窗)
- 大号时间显示
- 提醒标题
- 提醒备注
- 贪睡按钮（延迟5/10/15分钟）
- 关闭按钮
- 背景半透明毛玻璃效果

### 4. 标签管理页面
- 标签列表（颜色圆点 + 名称）
- 添加标签
- 编辑标签（名称、颜色）
- 删除标签

## 🔔 提醒触发流程

```
系统时间到
    ↓
AlarmManager 触发 BroadcastReceiver
    ↓
判断提醒是否有效（未被删除/禁用）
    ↓
┌──────────────────────────────────────┐
│ 并行触发三种提醒方式                   │
│                                      │
│ 1. 通知：创建通知渠道 → 发送通知       │
│ 2. 响铃：启动 Foreground Service →   │
│    MediaPlayer 播放铃声              │
│ 3. 震动：Vibrator 按模式震动          │
└──────────────────────────────────────┘
    ↓
如果用户未操作 → 持续响铃直到关闭或贪睡
    ↓
用户操作：
   ├─ 关闭 → 停止响铃/震动，标记完成
   └─ 贪睡 → 停止响铃/震动，设置 X 分钟后 AlarmManager 重新触发
```
